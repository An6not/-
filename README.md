# 🎮 3D Multiplayer Platform Game

Кроссплатформенная 3D онлайн игра с P2P соединением по 5-значному коду комнаты.

## 🚀 Как запустить

1. Откройте файл `index.html` в браузере
2. Для мультиплеера откройте игру в двух разных браузерах/устройствах

## 🎮 Управление

### ПК (Клавиатура)
- **← / A** - Движение влево
- **→ / D** - Движение вправо
- **↑ / W / Пробел** - Прыжок

### Мобильные устройства
- **Виртуальный джойстик** (слева) - Движение влево/вправо
- **Кнопка "Прыжок"** (справа) - Прыжок
- **Кнопка полноэкранного режима** (справа) - Полноэкранный режим

## 🌐 Как играть по сети

### Создание комнаты
1. Нажмите "Создать комнату"
2. Подождите генерации 5-значного кода
3. Поделитесь кодом с другом

### Присоединение к комнате
1. Нажмите "Присоединиться к комнате"
2. Введите 5-значный код комнаты
3. Нажмите "Подключиться"

## 📋 Особенности

- **3D графика** на Three.js
- **P2P соединение** через WebRTC (PeerJS) с улучшенной обработкой ошибок
- **5-значные коды комнат** для простого подключения
- **Кроссплатформенность** - работает на ПК и мобильных
- **Виртуальный джойстик** для мобильных устройств (nipplejs)
- **Мультитач поддержка** для одновременного использования джойстика и кнопок
- **Кнопка полноэкранного режима** для мобильных
- **Синхронизация игроков** в реальном времени
- **3D платформы** для прыжков
- **Динамическая камера** следящая за игроком
- **Автоматическое масштабирование** под размер экрана

## 🔧 Технологии

- Three.js (3D рендеринг)
- JavaScript
- PeerJS (WebRTC P2P)
- nipplejs (виртуальный джойстик)
- CSS3

## ⚠️ Важно

- Оба игрока должны иметь доступ к интернету
- Для P2P соединения используется публичный signaling server PeerJS
- Код комнаты состоит ровно из 5 цифр
- При проблемах с соединением игра автоматически пытается переподключиться (до 3 попыток)
