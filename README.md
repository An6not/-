# fffaa 3D P2P

3D-игра от первого лица с P2P-подключением и двухэтажной картой, улучшенным фонариком и гибкими настройками графики. Простая и красивая арена с внутренними стенами, платформами для подъёма на второй этаж, фонариком с мерцанием и несколькими уровнями настроек!

## Основные возможности

- **Двухэтажная карта**: Большая арена с внутренними стенами и платформами для подъёма на второй этаж
- **Фонарик**: Быстрый отклик, мерцание и покачивание при движении
- **Настройки графики** (4 уровня + авто):
  - **Минимум**: Максимальная оптимизация (простые материалы, нет теней, минимальная детализация
  - **Низкие**: Отличная производительность (простые материалы, нет теней, низкая детализация
  - **Средние**: Баланс (качества и производительности (качества и производительности
  - **Ультра**: Максимальное качество (качественные материалы, мягкие тени, максимальная детализация, полное сглаживание
  - **Авто-настройка**: Автоматически подбирает оптимальный уровень
- **P2P**: Подключение по 5-значному коду
- **Улучшенный интерфейс**: Разные стили меню для ПК и телефона
- **Адаптивность**: На телефоне по умолчанию выбираются низкие настройки

## Запуск

Откройте `index.html` в браузере. Для P2P откройте игру на двух устройствах или в двух разных браузерах.

## Управление

### ПК
- `WASD` или стрелки - движение относительно направления камеры
- `Пробел` - прыжок
- `Мышь` (зажатием - обзор от первого лица
- `Shift` - быстрый бег
- `F` - включить/выключить фонарик
- `Клик по экрану` - включить обзор мышью

### Телефон
- Левый виртуальный джойстик - движение относительно направления камеры
- Правая часть экрана - обзор
- `Прыг` - прыжок
- `F` - включить/выключить фонарик
- `⛶` - полноэкранный режим

## P2P подключение

1. Первый игрок нажимает `Создать комнату`.
2. Игра показывает 5-значный код.
3. Второй игрок нажимает `Подключиться`, вводит код и входит.

Внутри используется PeerJS/WebRTC. Код комнаты связан с PeerJS ID формата `fffaa-12345`. Позиции отправляются примерно 30 раз в секунду, а удалённый игрок рисуется через буфер интерполяции, чтобы движение было плавнее у обеих сторон.

## Библиотеки

- **Three.js** - 3D-сцена
- **PeerJS** - P2P/WebRTC
- **nipplejs** - мобильный виртуальный джойстик
