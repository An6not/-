# дед - 3D P2P игра

3D-игра от первого лица с P2P-подключением, полностью переработанным интерфейсом и оптимизированными настройками! Двухэтажная карта с улучшенным дизайном, гибкие графические пресеты (в том числе автоматическая настройка) и фонарик, работающий даже на минимальных настройках!

## Основные возможности

- **Переработанное меню**: Атмосферный фон и стильные элементы с плавными анимациями
- **Настройки графики** (4 уровня + авто):
  - **Минимум**: Легко даже на слабых устройствах
  - **Низкие**: Высокий FPS без видимой потери качества
  - **Средние**: Баланс качества и производительности
  - **Ультра**: Максимальная детализация
  - **Авто-настройка**: Улучшенный алгоритм, который правильно подбирает настройки под мощное железо
- **Улучшенный фонарик**: Работает на всех настройках (только тени отключаются на минимальных)
- **Двухэтажная карта**: Чистая симметричная структура с внутренними стенами и платформами
- **Полная адаптивность**: Разный интерфейс для ПК и телефона
- **P2P-подключение**: Подключение по 5-значному коду

## Запуск

Откройте `index.html` в любом браузере. Для P2P-режима откройте игру на двух устройствах или в разных браузерах.

## Управление

### ПК
- `WASD` / стрелки — движение
- Пробел — прыжок
- Shift — спринт
- Клик по экрану — включить обзор мышью
- F — включить/выключить фонарик

### Телефон
- Левый виртуальный джойстик — движение
- Правая часть экрана — обзор
- Кнопки в правом нижнем углу: прыжок, фонарик, полный экран

## Библиотеки

- Three.js (3D)
- PeerJS (P2P)
- nipplejs (мобильный джойстик)
