# fffaa 3D P2P

Простой 3D-прототип от первого лица: пока задача игры - ходить и прыгать по большой платформе. Есть начальное меню, управление для ПК и телефонов, мультитач для джойстика/обзора/прыжка, fullscreen-кнопка и P2P через 5-значный код.

## Запуск

Откройте `index.html` в браузере. Для проверки P2P откройте игру на двух устройствах или в двух разных браузерах.

## Управление

ПК:
- `WASD` или стрелки - движение
- `Пробел` - прыжок
- мышь - обзор от первого лица
- `Shift` - быстрый бег

Телефон:
- левый виртуальный джойстик - движение
- правая часть экрана - обзор
- `Прыг` - прыжок
- `⛶` - полноэкранный режим

## P2P

1. Первый игрок нажимает `Создать комнату`.
2. Игра показывает 5-значный код.
3. Второй игрок нажимает `Подключиться`, вводит код и входит.

Внутри используется PeerJS/WebRTC. Код комнаты напрямую связан с PeerJS ID формата `fffaa-12345`, поэтому подключение происходит именно по показанным пяти цифрам. Позиции отправляются чаще, а удалённый игрок рисуется через небольшой буфер интерполяции, чтобы движение выглядело плавнее у обеих сторон.

## Библиотеки

- Three.js - 3D-сцена
- PeerJS - P2P/WebRTC
- nipplejs - мобильный виртуальный джойстик
