# fffaa 3D P2P

3D-игра от первого лица с P2P-подключением и двумя этажами, улучшенным фонариком и оптимизированной графикой. Простая 3D-арена с внутренними стенами, платформами для подъема, двуми этажами, фонариком с мерцанием и выбором уровня графики.

## Основные возможности

- **Двухэтажная карта**: Большая арена с внутренними стенами и платформами для подъема на второй этаж
- **Фонарик**: Мгновенный отклик, мерцание и покачивание при движении
- **Настройки графики**:
  - **Низкие**: Максимальная оптимизация (простые материалы, без теней, низкий разрешение теневых карт, меньшее количество полигонов
  - **Ультра**: Максимальное качество (качественные материалы, мягкие тени, много полигонов, полное сглаживание)
- **P2P**: Подключение по 5-значному коду
- **Улучшенный UI**: Разные стили меню для ПК и телефона
- **Адаптивность**: На телефоне по умолчанию выбираются низкие настройки
- **Оптимизация**: Динамические настройки для разных устройств

## Запуск

Откройте `index.html` в браузере. Для P2P откройте игру на двух устройствах или в двух разных браузерах.

## Управление

### ПК
- `WASD` или стрелки - движение относительно направления камеры
- `Пробел` - прыжок
- `Мышь` - обзор от первого лица (зажми нажатием)
- `Shift` - быстрый бег
- `F` - включить/выключить фонарик
- `Клик по экрану` - включить обзор мышью

### Телефон
- Левый виртуальный джойстик - движение относительно направления камеры
- Правая часть экрана - обзор
- `Прыг` - прыжок
- `F` - включить/выключить фонарик
- `⛶` - полноэкранный режим

## P2P подключение

1. Первый игрок нажимает `Создать комнату`.
2. Игра показывает 5-значный код.
3. Второй игрок нажимает `Подключиться`, вводит код и входит.

Внутри используется PeerJS/WebRTC. Код комнаты связан с PeerJS ID формата `fffaa-12345`. Позиции отправляются примерно 30 раз в секунду, а удалённый игрок рисуется через буфер интерполяции, чтобы движение было плавнее у обеих сторон.

## Настройки графики

- **На телефоне**: По умолчанию выбираются **Низкие** настройки для лучшей производительности
- **На ПК**: По умолчанию выбираются **Ультра** настройки для лучшего качества
- Вы можете изменить уровень перед началом игры в меню

## Библиотеки

- **Three.js** - 3D-сцена
- **PeerJS** - P2P/WebRTC
- **nipplejs** - мобильный виртуальный джойстик
