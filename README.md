# 🎮 Multiplayer Platform Game

Кроссплатформенная онлайн игра с P2P соединением по 5-значному коду комнаты.

## 🚀 Как запустить

1. Откройте файл `index.html` в браузере
2. Для мультиплеера откройте игру в двух разных браузерах/устройствах

## 🎮 Управление

### ПК (Клавиатура)
- **← / A** - Движение влево
- **→ / D** - Движение вправо
- **↑ / W / Пробел** - Прыжок

### Мобильные устройства
- Кнопки на экране:
  - **←** - Влево
  - **↑** - Прыжок
  - **→** - Вправо

## 🌐 Как играть по сети

### Создание комнаты
1. Нажмите "Создать комнату"
2. Подождите генерации 5-значного кода
3. Поделитесь кодом с другом

### Присоединение к комнате
1. Нажмите "Присоединиться к комнате"
2. Введите 5-значный код комнаты
3. Нажмите "Подключиться"

## 📋 Особенности

- **P2P соединение** через WebRTC (PeerJS)
- **5-значные коды комнат** для простого подключения
- **Кроссплатформенность** - работает на ПК и мобильных
- **Синхронизация игроков** в реальном времени
- **Платформы** для прыжков
- **Автоматическое масштабирование** под размер экрана

## 🔧 Технологии

- HTML5 Canvas
- JavaScript
- PeerJS (WebRTC)
- CSS3

## ⚠️ Важно

- Оба игрока должны иметь доступ к интернету
- Для P2P соединения используется публичный signaling server PeerJS
- Код комнаты состоит ровно из 5 цифр
